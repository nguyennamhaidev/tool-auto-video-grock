# Video Factory AI (CHO HAI XIN 1 SAO GITHUB)

## Cai dat

Yeu cau: Windows, Python 3, Google Chrome.

```powershell
.\setup.ps1
```

Hoac:

```bat
setup.bat
```

## Chuan bi

- Nhac nen: `assets/music/`
- Anh nhan vat: `assets/characters/`
- Lan dau chay: dang nhap X/Grok trong cua so Chrome tool mo ra.

## Chay tool

```powershell
.\run.ps1
```

Hoac:

```bat
run.bat
```

## Su dung nhanh

1. Chon `Lam phim AI` hoac `Ban hang AI`.
2. `Lam phim AI`: chon `Nhap kich ban`, `ChatGPT viet`, hoac `Hang loat`.
3. Chon anh nhan vat, ty le khung, giong doc, nhac nen va thu muc output neu can.
4. Bam `Mo Chrome Grok`, dang nhap neu tool yeu cau.
5. Bam `BAT DAU`.
6. Video nam trong `output/`.

## Loi thuong gap

- Thieu thu vien: chay lai `setup.ps1` hoac `setup.bat`.
- Grok chua dang nhap: mo lai Chrome Grok va dang nhap lai.
- Khong co nhac nen: de trong muc nhac hoac bo file vao `assets/music/`.
